# Introduction
Pretty simple, this repo contains all the cheats available in
https://github.com/iSharingan/CTRPF-AR-CHEAT-CODES/blob/master/README.md 
Converted into the structure expected by Luma3DS's cheat engine.

# Usage
1. Copy the folder `luma` to the root of your SD card.
2. Go use the cheats in your favorite game!
